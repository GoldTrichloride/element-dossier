# Element Dossier
## 元素户口簿
Element Household Register — Nuclear & chemical dossier collection for all 118 chemical elements.

> ⚠️ 本仓库仅存放【元素户口簿】项目，与学术元素周期表仓库相互独立。
> ⚠️ This repository only hosts the Element Household Register project. It is separate from the academic periodic tables repository.
